# JJ action items

Held back from this public copy.

The real file is the list of things only JJ can do, appended to by every agent that finds one.
It is in the private repository `JJtmc1234/army-memory`.

It is held back because of what the entries say rather than what the file is for. They name his
teachers, the classes they set and when they meet, an investor and an unsent reply to her, and
the path to a key on his machine. None of that is dangerous on its own. Together it is a
schedule of where a child is and who is with him.

## How it works, which is the part worth publishing

Agents append to the bottom. They never reorder and never edit a line that is already there,
because several of them write to it and a whole file write from any one would lose what another
added in between. Miles does not even write to it himself: he prints lines beginning with
`ACTION:` and `run.sh` appends them, so there is one writer instead of several.

The format is one line each:

```
- [ ] <what to do> · <why it is blocked on JJ> · <source>
```

Ticked with `[x]` and left in place rather than deleted, so the list is also a record of what
was asked and answered. JJ writes his answer inside the brackets when it is not a simple yes,
and `[DONE]` and `[done]` both appear because people are not consistent and the file is read by
people.

The rules that govern it are in `shared/work/action-items.md`, which is not held back.
