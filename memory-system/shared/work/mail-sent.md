# Mail sent by an agent

Every send an agent makes, one line each, newest at the bottom. Append, never edit, never
delete. JJ has to be able to find out who received something from him without reading his whole
sent folder.

Format: `YYYY-MM-DD HH:MM · <agent> · <to> · <why> · <first few characters of what arrived>`

The gibberish auto reply must be logged here. So must anything else an agent sends.
